# AGAPE Inventory Optimizer — Fase 1

Aplicación web en español desarrollada con React, TypeScript, Tailwind CSS y Recharts.

## Ejecutar localmente

Requisitos: Node.js 20 o superior.

```bash
npm install
npm run dev
```

Abrir la dirección que muestra Vite (normalmente http://localhost:5173).

## Publicar

Puedes importar este proyecto a GitHub y desplegarlo en Vercel o Netlify como proyecto Vite. Comando de compilación: `npm run build`. Carpeta de salida: `dist`.

## Alcance

Incluye validación de entradas, cálculo EOQ, redondeo por comparación de costos, gráfico interactivo, interpretación gerencial y desarrollo matemático. No incluye autenticación, persistencia ni cálculo de punto de reorden. Datos de AGAPE: simulación académica.
